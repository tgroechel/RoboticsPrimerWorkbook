# Robotics Primer Coding Workbook

Welcom to the Robotics Primer Coding Workbook. The workbook is created to work on all operating systems that support the [Unity Game Engine](https://unity.com/) (Windows/MacOS/Linux). 

## Getting Started
1. Download and install Unity Hub/Unity: This workbook was written in Unity version 2020.3.11f1. Downloading Unity can be found [here](https://unity3d.com/get-unity/download) with the archive of all Unity versions [here](https://unity3d.com/get-unity/download/archive). It is strongly advised to use Unity Hub for installing Unity versions and to use the exact same version. All exercises were built inside the editor and can be run using just the play button.
2. Download and unzip this repository.
3. Open up Unity Hub and click the `Add` button
4. Navigate to where the folder was unzipped to and open it.
5. This should launch the project, if you have any issues you can consult Unity's documentation [here](https://docs.unity3d.com/Manual/GettingStartedOpeningProjects.html).

Congratualtions, you are ready to get started. All exercises can be found in the `Assets/Exercises` folder. Each of these folders contains a `README.md` with directions. To view a more friendly version of the `README.md`, you can navigate to its link online (e.g., [Exercise 1](Assets/Exercises/1.%20PID/) or download a Markdown viewer.
